# nixos-config

Пересобрать систему:  sudo nixos-rebuild switch --flake ~/nixos-config#nixos
Обновить пакеты:      nix flake update && sudo nixos-rebuild switch --flake ~/nixos-config#nixos

Хоткеи:
Super+Enter терминал | Super+D лаунчер | Super+B браузер | Super+E файлы | Super+C VS Code
Super+V история буфера | Super+Q закрыть окно | Super+Shift+V плавающее окно | Super+F фулскрин
Super+1..9 воркспейсы | Super+Shift+1..9 перенести окно | Super+Shift+S скриншот
Super+L блокировка | Super+Shift+M выход | Alt+Shift раскладка

# nixos-config

Пересобрать систему:  sudo nixos-rebuild switch --flake ~/nixos-config#nixos
Обновить пакеты:      nix flake update && sudo nixos-rebuild switch --flake ~/nixos-config#nixos
Тема: Stylix + Tokyo Night (modules/theme.nix, home/theme.nix)

Хоткеи:
Super+T терминал | Super+A приложения | Super+B Zen | Super+E файлы | Super+C VS Code
Super+V история буфера | Super+Q закрыть окно | Super+Shift+V плавающее | Super+F фулскрин
Super+1..9 воркспейсы | Super+Alt+1..9 перенести окно | Ctrl+Super+←/→ соседний стол
Super+S скрытое пространство | Super+Alt+S окно туда
Super+Shift+S скриншот | Super+L блокировка | Super+Shift+M выход | Alt+Shift раскладка

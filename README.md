# nixos-config

Пересобрать систему:  sudo nixos-rebuild switch --flake ~/nixos-config#nixos
Обновить пакеты:      nix flake update && sudo nixos-rebuild switch --flake ~/nixos-config#nixos

Хоткеи: Super+Enter терминал, Super+D лаунчер, Super+B браузер, Super+Q закрыть окно,
Super+1..9 воркспейсы, Super+Shift+S скриншот, Super+L блокировка, Alt+Shift раскладка.
